# LOVESY
What **LOVESY** stands for? Well, it stands for "`L`inco's `OV`er`E`ngineered `S`tupid `Y`t-dlp wrapper", of course!

## Erm, so
**LOVESY** (bold, all caps, don't forget) is a simple set of `bash` scripts I made to automate some yt-dlp routines I constantly
use...or at least it was meant to be: somewhere in the way, I got carried away and decided to overthink how the whole
thing works. Whoops.

I doubt **LOVESY** will be useful to anyone out there except to my _automation freak_ guts, but feel free to use it yourself.
There's a `-h` option that lists the available arguments you can pass to the main script.

## Requirements
All you need is a way to run bash (duh), and [yt-dlp](https://github.com/yt-dlp/yt-dlp) installed and available as a command, pretty much.

## Running it
The file you want to run is `ytd-wrapper.sh`. It's not like you need to _worry_ about running the wrong file or anything, though: I overengineered a way to check if you're running the script from the right place!!! ~~I should really value my time more.~~
